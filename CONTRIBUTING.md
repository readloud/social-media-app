## Panduan Kontribusi

### Setup Development

```bash
git clone https://github.com/readloud/social-media-app.git
cd social-media-app
npm run setup
```

### Pull Request Process

1. Update dokumentasi jika diperlukan
2. Pastikan semua test passing
3. Dapatkan approval minimal 2 reviewer
4. Merge hanya setelah CI/CD green

### Code of Conduct

Kami berkomitmen untuk menyediakan lingkungan yang ramah dan bebas intimidasi.
