## Security Policy

### Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x.x   | ✅ |
| < 1.0   | ❌ |

### Reporting a Vulnerability

Email ke **security@yourdomain.com** dengan detail:
- Deskripsi vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (opsional)
